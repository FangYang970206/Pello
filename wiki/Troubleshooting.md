# 遇到问题，先检查这些

| 现象 | 先做什么 |
| --- | --- |
| Agent 启动失败 / 命令不存在 | 先在同一环境用「仅 Shell」执行原生命令，核对 CLI、PATH 与认证；SSH 工具要装在远端 |
| SSH 拒绝连接 | 核对地址、端口、SSH 服务；WSL 地址可能变化。见 [SSH 指南](SSH-and-Transfer) |
| 认证失败 | 核对用户名、密钥/Agent/密码与远端认证策略，不反复保存错误主机 |
| 主机指纹变化 | 先确认服务器身份和密钥变化原因 |
| 文件保存冲突 | 保留草稿，检查外部修改和权限，比较后再处理。见 [文件保存](Files-and-Editing) |
| 文本打不开 | 检查 UTF-8、2 MB 文本限制；PDF/图片走 12 MB 媒体预览 |
| 搜索无结果 | 核对大小写、全字、正则、忽略规则；点目录与二进制不会参与内容搜索 |
| 新 MCP / Skill 不出现 | 确认分发目标与开关，按 Agent 原生方式重新加载；导入不等于服务器已认证 |
| 恢复失败 | 保留标签和错误，核对网络、CLI 与原生会话文件；可右键重新连接，不把历史回放当成对话续接成功 |
| 更新按钮不可用 | 开发版不检查更新；发行版见[更新与数据](Updates-and-Data) |
| 安装目录不可写 | 换到当前用户可写的安装位置，应用不会自动回退用户目录 |

## 反馈时带上什么

在[问题反馈](https://github.com/FangYang970206/Pello/issues)写明「关于」页版本、系统、执行器版本、最短复现步骤、预期与实际结果。截图与日志请移除密码、令牌和私人内容。
