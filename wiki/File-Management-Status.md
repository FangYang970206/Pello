# 文件管理支持到哪里

以下范围对应当前实现。常用入口见 [日常操作](Workspace)，完整操作演示使用独立示例项目。

| 已支持 | 使用入口 |
| --- | --- |
| 逐层目录加载、递归搜索、项目级忽略规则 | 文件面板；设置 → 通用 |
| 文件名搜索与项目内容搜索（大小写、全字、正则，Ctrl+E / Ctrl+Shift+F） | 文件面板；跳过点目录，沿用忽略规则 |
| 新建、重命名、移动、删除、复制路径、打开方式 | 文件树右键菜单 |
| 文件预览、编辑、自动保存、撤销与冲突保护 | 文件标签与正文右键菜单 |
| 查找替换（Ctrl+F / Ctrl+H）与 Ctrl+滚轮阅读缩放 | 文件与 Diff；Markdown 渲染模式同样可用 |
| Markdown 渲染与标题目录、HTML 沙箱预览 | 文件标签；正文右键切换源码 |
| PDF 与 PNG、JPEG、GIF、WebP、BMP、SVG、ICO、AVIF 只读预览 | 文件标签；缩放 25%–400%，PDF 支持翻页 |
| 本机导入、SSH 上传、下载与另存为 | 文件树右键菜单 |
| 上传单行状态、取消、失败重试与成功后自动清除 | 文件面板底部 |
| 远程同名文件覆盖、同名目录整体替换 | 远程上传，保留草稿确认 |

## 使用前留意

- 远程上传整目录会移除旧目录独有内容。先完成临时上传与版本检查再发布，失败或取消不会提前清空旧目录。
- 发布后的旧备份清理失败时，界面会告知保留位置。
- 下载、另存为和移动尚未共用完整的覆盖与草稿联动流程，请先核对目标。
- 内容搜索跳过二进制、非 UTF-8 和超过 2 MB 的文件；达到 2000 个匹配时提示缩小范围。
