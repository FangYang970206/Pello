# 一次任务的完整路线

这页是一张操作地图；每个入口都有独立的教学动图与可核对的完成标志。

1. **启动**：[添加项目与终端](Getting-Started)，选择[执行器](Executors)。
2. **组织**：[按任务建会话](Sessions)，必要时开[临时任务](Sessions#临时任务不必建正式项目)。
3. **定位**：[项目搜索](Project-Search)找文件或内容，[终端搜索与高亮](Terminal)标记线索。
4. **阅读**：[Markdown / HTML](Markdown-and-HTML)、[PDF / 图片](Media-Preview)留在文件标签中。
5. **修改**：[编辑与保存](Files-and-Editing)、[查找替换](Find-and-Replace)共享文件草稿和撤销。
6. **对照**：[混合分栏](Split-Workspace)让终端与代码并排，[Git Diff](Git-Review)检查改动。
7. **收尾**：保存文件，在终端中运行项目检查与 Git 命令。退出后按[会话恢复](Sessions#退出后恢复什么)继续工作。

远端项目从 [SSH 指南](SSH-and-Transfer)进入；Agent 工具在 [MCP / Skill](Agent-Resources)配置；阅读习惯在[外观](Appearance)调整；升级与备份见[应用更新](Updates-and-Data)。

快捷键以应用「设置 → 快捷键」为准。终端关闭会要求确认；保存冲突先保留草稿，不能忽略外部文件变化。
